## v0.4.0-beta.2 — английский по умолчанию и выбор языка (2026-11-11)

Бета для сбора обратной связи от англоязычной аудитории.

### Язык

- Интерфейс по умолчанию — **английский**. При первом запуске окно спрашивает язык (предлагается язык браузера, галочка «Запомнить выбор» включена); потом язык меняется кнопкой EN / RU. Прежний сохранённый выбор не сбрасывается.
- Консоль, справка и сообщения об ошибках берут **язык системы** (Windows — язык интерфейса, в других системах `LC_ALL` / `LANG`; всё, кроме русского, — английский). Переопределение: `--lang en|ru` или `STARDEW_TRACKER_LANG`.
- Ошибки чтения сейва, предупреждения парсера и ответы HTTP API двуязычные: страница показывает ошибку на выбранном в интерфейсе языке, а не на языке консоли.
- В английском интерфейсе названия предметов показываются только по-английски; в русском — русское название и рядом английское.
- Сообщения `run.bat`, `report.bat` и `build_app.bat` — на двух языках.

### Обратная связь

- В бета-сборках внутри приложения есть плашка: «Вопросы, баги и предложения — repro4chful@gmail.com или GitHub Issues». Её можно закрыть (запоминается отдельно для каждой версии).
- README на английском (`README.md`), русская версия — `README.ru.md`; журнал изменений на английском (`CHANGELOG.md`), русский — этот файл; в репозитории появились шаблоны issue.

### Формулировки

- Тексты не предполагают пол читателя: в предупреждении раздела «Секреты» — «догадаться самому»; если в сейве нет имени игрока, приветствие — просто «Привет!».

### Исправления

- `tools/build_demo.py` падал с `UnicodeEncodeError` в консоли Windows (cp1252) при печати кириллицы; теперь сообщения английские, а демо — по вымышленной ферме Sunny Acres с английскими именами.
- Состояние копируется через `deepcopy`; двуязычные тексты теперь неизменяемы и копируются корректно.
- В состояние добавлено `meta.app_version` (по нему страница решает, показывать ли плашку беты).

## v0.4.0-beta.1 — первая бета (2026-11-11)

Накопленные изменения после v0.3.0. Это **бета**: интерфейс переработан только частично (этап 1 из 4 редизайна), сборки для macOS и Linux проверены лишь автоматическим smoke-тестом.

### «Секреты» по требованию

- Решения раздела «Секреты · danger zone» (~30 КБ) больше не лежат в каждом ответе `/api/state` и в исходнике страницы: интерфейс обещает показывать их только после согласия, и теперь живой сервер отдаёт их отдельным `GET /api/secrets` лишь после него. При выходе из раздела страница их забывает. Автономный отчёт (`build`), у которого нет сервера, по-прежнему содержит всё внутри. Это защита от случайного спойлера (просмотр исходника, отладчик), а не секрет: данные отдаются любому, кто запросит их сам.
- `GET /?save=…` больше не переключает активный сейв (побочный эффект в GET, который можно было вызвать межсайтовым запросом). Переключение — только `POST /api/saves/select`.
- Тесты: 275; проверено в браузере на реальных сейвах: исходник без решений → согласие → подгрузка 5 разделов и 40 записей → раскрытие спойлера → выход очищает кэш.

### Демо и инструменты

- Демо `docs/index.html` пересобрано и теперь генерируется скриптом `tools/build_demo.py`: без текущего времени, часового пояса, локальных путей и `goals.json`, поэтому одинаковые исходники дают одинаковый файл. Прежнее демо отставало от кода и содержало путь `/tmp/stardew-aqa/…`.
- CI проверяет актуальность демо (`python tools/build_demo.py --check`): после правок `assets/dashboard.html` или `data/` его нужно пересобрать.

### Исправления по реальным сейвам 1.6

Найдены проверкой на реальных сейвах 1.5.6 и 1.6.15 (`docs/AUDIT.md`, «Находки второго прохода»).

- **Сейвы 1.6: флаги доступа не читались.** `hasSkullKey`, `hasRustyKey`, `hasDarkTalisman`, `hasMagicInk`, `hasClubCard` в XML пустые, а настоящие значения лежат в письмах (`HasSkullKey`…). Из-за этого Пещера Черепа, Болото ведьмы и Логово мутантов показывались закрытыми у тех, кто там давно побывал, а рыба оттуда не попадала в «ловится сейчас». Теперь флаг берётся из тега или из письма.
- Письмо о членстве в Joja называется `JojaMember`, а код искал `jojaMember`: на пути Joja Логово мутантов считалось закрытым. Сравнение писем теперь без учёта регистра.
- Уже пойманная рыба (Рыба Ночного рынка, Лосось Пустоты) больше не помечается 🔒 «закрыто».
- Список ферм наконец берётся из `SaveGameInfo`: реальный файл хранит дату под именами `...ForSaveGame`, и быстрая сводка из предыдущего изменения на настоящих сейвах не срабатывала. Список из 4 ферм: 2367 → 85 мс.
- Тесты: 248; генератор тестового сейва пишет `SaveGameInfo` в реальной структуре, а новые тесты проверяют формат 1.6 (флаги в письмах), реальный `SaveGameInfo`, путь Joja и пойманную рыбу.

### Архитектурный аудит и рефакторинг

Подробности, замеры и открытые вопросы — в `docs/AUDIT.md`, раздел 7b.

**Исправленные ошибки**

- `perfectionWaivers` не находился в реальных сейвах (поиск шёл по первым 5000 узлам, а игра хранит тег после огромного `<locations>`), и ненулевые послабления перфекции терялись (проверено на реальных сейвах: тег лежит на узле ~208–263 тыс.). Теперь теги корня читаются напрямую.
- Наблюдатель за сейвом помечал файл «обработанным» до разбора: кратковременный сбой оставлял состояние устаревшим. Теперь повтор с нарастающей паузой (не более 5 раз), одна печать повторяющейся ошибки; результат для прежней фермы не затирает только что выбранную.
- `POST /api/goals` теперь читает пометки и пишет цели под одним замком (параллельные запросы теряли пометки).
- Вставка состояния в `<script>` экранирует `<!--`, U+2028 и U+2029 (строка из чужого сейва могла сломать страницу).

**Безопасность**

- Проверка заголовка `Host` на loopback-привязке (DNS-rebinding): чужое имя хоста — 403.

**Производительность**

- Разбор сейва в 23 МБ: 7,3 → ~3,0 с (один обход дерева вместо шести).
- Опрос вкладки: вместо ~450 КБ и ~26 мс CPU каждые 3 с — `GET /api/version` в ~60 байт; состояние скачивается только при смене ревизии. `/api/state` отдаёт `ETag` (304) и gzip (−85%), JSON сериализуется один раз на ревизию. Внешняя правка `goals.json` подхватывается одним `stat`.
- Список ферм берётся из `SaveGameInfo`, а не полным разбором каждого сейва; блокировка разбора — на файл.

**Рефакторинг**

- `SaveError` больше не наследует `SystemExit` (иерархия `TrackerError` → `SaveError` → `DataError`); в консоли поведение прежнее.
- Модули переименованы: `collections` → `rows` (затенял стандартную библиотеку), `requirements` → `unlocks`, `render` → `report` (функция `render` по-прежнему экспортируется).
- Веса перфекции записаны один раз; порядок суммирования сохранён (в Python 3.12+ `sum()` на границе округления даёт другой процент).
- `build_state` разбит на `_load_reference`, `_build_meta`, `_build_alerts`.
- Тесты: 228 (было 161); `tests/make_test_save.py --pad-objects N` создаёт раздутый сейв для замеров.

Заголовки всех страниц получили единый вид (капс, кикер с названием группы).

## v0.3.0 — условия получения, фильтры, светлая тема и danger zone (2026-11-10)

**Исправленные ошибки**

- Перфекция считалась неверно: коллекция рыбы в 1.6 — 72 вида (с тремя медузами, без «легендарных II»), а не 74; полная отправка — 154 предмета (Гребешок в 1.6 стал рыбой), а не 155.
- Рыба Ночного рынка (Ночной кальмар, Жуть-рыба, Рыба-капля) показывалась «доступной сейчас» в любой сезон — теперь только зима 15–17, 17:00–02:00. Лавовому угрю добавлен 100-й этаж Шахт.
- «Сейчас ловится» и план на день больше не советуют рыбу из закрытых локаций и «легендарных II».
- `TrackerApp.allowed_save_paths` падал с `UnboundLocalError`, если поиск сейвов выбрасывал ошибку; запись `goals.json` при ошибке диска отвечала 400 вместо 500.
- Парсер: пустой `<stats/>` фермера подменялся чужим блоком (проверка истинности `Element`, заодно ушёл `DeprecationWarning`); `norm_id("(O")` падал с `IndexError`.
- `build_data.find_file` возвращал смешанный путь в Windows (тест был красным).
- Интерфейс: на каждое нажатие клавиши в поиске уходил запрос `/api/saves` (теперь список кэшируется); у жителей без даты рождения выводилось «null дн.»; время рыбы показывалось как «26:00», а два окна склеивались в «06:00–11:00–19:00–02:00»; кнопка «Скрыть готовое» вместе с фильтром «Готово» давала пустой список (кнопка убрана); автообновление могло откатить только что поставленную пометку ★ и перерисовывало страницу во время набора текста.

**Новое**

- Модуль `requirements.py`: обязательные условия (остров, Комната Ки, пустыня, Пещера Черепа, канализация, Логово мутантов, Болото ведьмы, Тайный лес, этажи шахт, мастерство, теплица, погреб, навыки, сердца, расписание Ночного рынка). Статус берётся из сейва (`hasRustyKey`, `hasSkullKey`, `hasDarkTalisman`, письма, орехи, уровень дома, топор в инвентаре); если по сейву не понять — честное «проверьте сами».
- Рыба, артефакты, отправка и рецепты получают `lock`/`req`; в списках — пометка 🔒 «Нужно открыть: …» (для Ночного рынка — «Ждите: …») и подсказка «Как открыть»; панель «Ключи и доступы» на странице «Сегодня».
- Точные источники рецептов (`data/recipe_sources.json`, сверены с вики 1.6) вместо «Магазин / Событие» и «Level / TV (10)».
- Фильтры: рыба — место, время суток или «сейчас в игре», сезон, погода, снасть; музей — где искать; отправка — сезон и категория; рецепты — источник; везде — «Доступно мне / Требует открытия». Фильтры запоминаются. Поиск по жителям.
- Раздел «Секреты · danger zone» (`data/secrets.json`): решения заданий мистера Ки, «Таинственного Ки», секретных записок и обрывков дневника. Экран-предупреждение с обязательным согласием при каждом входе, раздельное раскрытие подсказки и решения, текст замаскирован даже в DOM, предупреждения для ещё не открытых мест; счётчик выполненных заданий Ки из сейва.
- Визуал в спойлерах: иконки нужных предметов из игровых атласов, 13 собственных схем (SVG-карты мест и HTML-схемы: маршрут «Таинственного Ки», цвета «Радужной выставки», самоцветы кузни, порядок ракушек, настройка флейта-блоков) и ссылки на страницы вики со скриншотами. Визуал появляется только вместе с раскрытым решением; скриншоты игры в проект не встраиваются.
- Названия в danger zone приведены к официальной русской локализации: Qi — «Ки», Junimo — «джунимо», «Мисс Морской черт», «Ледорыб-младший», «Малек Багрянника».
- Новое оформление: все цвета вынесены в переменные; светлая тёплая тема по умолчанию, мягкая тёмная «ночная» и режим «как в системе»; новый статус «требует открытия» в легенде.
- Тесты: 157 (было 129), включая `test_requirements.py` и регрессии найденных багов; JS-синтаксис проверяется через Node.

## v0.2.0 — аудит, AQA и модульный рефакторинг (2026-11-08)

- Монолитный `tracker.py` (2114 строк) разбит на пакет `stardew_tracker/` из 20 модулей:
  поиск сейвов, безопасный XML-парсер, справочники, сборка состояния, перфекция, «Сегодня»,
  рендер, HTTP-сервер и CLI. `tracker.py` остался совместимым фасадом для старых команд.
- Безопасность: XML с `DOCTYPE`/`ENTITY` отклоняется; сервер по умолчанию слушает только
  `127.0.0.1` (явный `--host 0.0.0.0` для сети); добавлены CSP, `Referrer-Policy`, `nosniff`
  и скрыта версия Python в заголовке `Server`; сохранены запрет CORS и белый список сейвов.
- Исправлены ошибки: поток наблюдателя больше не умирает на `SaveError`; `farmhands`
  находятся и после 4000 XML-узлов; Farmer Level больше не учитывает удачу; кэши парсера и
  состояния получили блокировки, LRU и изоляцию изменяемых данных; `report.html` и
  `goals.json` пишутся атомарно; повреждённые `data/*.json` дают понятный `DataError`.
- Устранены гонки при параллельных запросах и сохранении целей; переключение сейва меняет
  активный файл только после успешного разбора; кэш спрайтов ключуется по пути.
- Добавлены `--host`, `--out`, `--version`, точка входа `python -m stardew_tracker` и
  `TrackerApp`/`TrackerHTTPServer` с фабрикой обработчика.
- Добавлена standalone-сборка: `packaging/build_app.py`, spec PyInstaller, `build_app.bat`
  и workflow **Build app** для Windows/macOS/Linux; в сборке `data/` и `assets/` читаются из
  бандла, а `goals.json`/`report.html` пишутся в каталог данных ОС (`STARDEW_TRACKER_HOME`
  переопределяет его).
- AQA: 129 тестов вместо 45, покрытие 90% (было 68%), новые тесты на XML-бомбы, окна времени,
  конкурентность, мультиплеер, PNG-кодек, CLI, жизненный цикл сервера и синтаксис inline-JS
  (`node --check`). CI получил жёсткие гейты ruff, format, mypy, bandit и coverage ≥85%.
- Дифференциальная проверка: состояние и HTML для синтетического сейва совпадают с v0.1.0
  с точностью до времени генерации.
- Подробный отчёт: `docs/AUDIT.md`.
